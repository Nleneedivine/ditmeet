# DITMeet

"Build a video conferencing web app called DIT Meet (DITM) with a dark navy blue theme, gold glowing accents, velvet curtain aesthetic, and animated rainbow/holographic highlights inspired by a 10th anniversary brand. Use the Daily.co SDK for video infrastructure.

Design & Branding:

Dark navy (#0a0a2e) background with subtle damask/floral texture pattern

Gold glowing edges and borders on all cards and buttons

Rainbow holographic accents on key UI elements

Animated glowing logo: "DITM" in gold with pulsing glow effect

Elegant serif + modern sans-serif font pairing

Authentication:

Google Sign-In (required) to create or schedule meetings

No login required to join — only a meeting link needed (they will enter their full name and email address for attendance tracking)

Home Dashboard (after Google login):

"Start Instant Meeting" button (glowing gold)

"Schedule Meeting" button — pick date, time, title, description

List of upcoming scheduled meetings with copy-link button

Meeting history list

Meeting Room UI:

Animated participant video grid (navy + gold bordered tiles)

Participant name tag on each tile with gold glow

Bottom control bar with: Mute/Unmute, Camera On/Off, Screen Share, Leave Meeting

Meeting timer displayed prominently at the top center (counts up)

Participant list sidebar showing who is in the meeting

Chat sidebar panel

Connect to Supabase for all data storage."
